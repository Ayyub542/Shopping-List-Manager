# 🛒 Shopping List Manager

A simple shopping list app built with HTML, CSS, and JavaScript. Add items with quantities, delete them when you're done, and keep track of the total. Your list is saved in the browser, so it's still there when you come back.

## Features

- Add items with a name and quantity
- Delete items individually
- Total quantity updates automatically
- Data persists using `localStorage`
- Clean, simple interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)

## Project Structure

```

├── SLM.html    # Page structure

└── README.md
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Ayyub542/Shopping-List-Manager.git
   ```
2. Open the folder:
   ```bash
   cd Shopping-List-Manager
   ```
3. Open `SLM.html` in your browser.

No installation or build step needed.

## How to Use

1. Enter an item name and quantity.
2. Click **Add Item**.
3. Click **Delete** to remove an item.
4. The **Total Items** counter shows the sum of all quantities.
